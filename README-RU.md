## Загрузка  

### Windows  

#### Официальная сборка  

Скачайте последнюю готовую сборку для Windows на вкладке [Releases](https://github.com/nazarhktwitch/BetterAyuGramDesktop/releases) или присоединяйтесь к обсуждению в [Telegram-чате](https://t.me/ayugramchat/12788).  

#### Сборка вручную  

Следуйте [официальному руководству](https://github.com/nazarhktwitch/BetterAyuGramDesktop/blob/dev/docs/building-win-x64.md), если хотите собрать клиент самостоятельно.  

### Требования для Windows  

Перед установкой убедитесь, что в VS Build Tools установлены следующие компоненты:  

- C++ MFC latest (x86 & x64)  
- C++ ATL latest (x86 & x64)  
- Последний Windows 11 SDK
