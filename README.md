## Downloads  

### Windows  

#### Official Build  

Get the latest prebuilt Windows binary from the [Releases tab](https://github.com/nazarhktwitch/BetterAyuGramDesktop/releases) or join the discussion in the [Telegram topic](https://t.me/ayugramchat/12788).  

#### Build It Yourself  

Follow the [official guide](https://github.com/nazarhktwitch/BetterAyuGramDesktop/blob/dev/docs/building-win-x64.md) to compile from source.

### Notes for Windows Users  

Ensure that the following components are installed via VS Build Tools:  

- C++ MFC latest (x86 & x64)  
- C++ ATL latest (x86 & x64)  
- Latest Windows 11 SDK
